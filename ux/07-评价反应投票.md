# 评价、短评、表态反应与投票

用户对作品的多维度互动：完整书评（REVIEW）、简短短评（REMARK）、表态反应（点赞/反对）、结构化投票（Poll）、评分与排序（Score）。

## 场景 1：浏览作品的全部书评

**入口/触发**：书籍详情「评价」标签或评价列表。

**前置条件**：书籍已发布；有书评。

**步骤**：
1. `/review/book/$bookId` — `package/app/src/routes/_mainLayout/review/book/$bookId.tsx:8`。
2. `ReviewByBookPage` — `package/app/src/review/pages/ReviewByBookPage.tsx:13`。
3. `bookQueries.detail()` 取元数据 — `package/api/src/book/book.ts`。
4. `postApi.getByTarget(bookUnitId,{kind:'REVIEW'})`（书评存为 Post，kind=REVIEW）— `package/api/src/post/post.api.ts:76`。
5. 后端 `getByTarget` — `package/server/src/post/post.api.ts:76`–`83`。

**关键数据流**：路由 → `ReviewByBookPage` → `postApi.getByTarget()` → `POST /post/list` → `postService.byTarget()` → 契约 `PostResponse`。

**边界/权限/异常**：仅已发布；未登录可浏览；支持按评分/时间排序。

## 场景 2：撰写新书评

**入口/触发**：详情/列表「写评价」。

**前置条件**：已登录；选定目标书籍。

**步骤**：
1. `/review/new/$bookUnitId` — `package/app/src/routes/_mainLayout/review/new/$bookUnitId.tsx:13`。
2. `ReviewNewPage` — `package/app/src/review/pages/ReviewNewPage.tsx:23`。
3. 表单：标题/评分(1-10)/内容(发布≥200 字)— `ReviewNewPage.tsx:37`–`43`。
4. 评分 → `useUpsertScoreMutation()` — `package/api/src/score/score.mutations.ts`。
5. 提交 → `useCreatePostMutation()`（kind=REVIEW）— `package/api/src/post/post.mutations.ts`。
6. `POST /post` 事务创建 Unit(POST,REVIEW)+Post+ContentDoc — `package/server/src/post/post.api.ts:163`–`250`。
7. `postService.createPost()` — `package/server/src/post/post.service.ts`。
8. 重定向 `/review/$reviewId`。

**关键数据流**：路由 → `ReviewNewPage` → createPost + upsertScore → `POST /post`+`POST /score` → postService+scoreService → 契约 `PostResponse`/`ScoreEntryDTO`。

**边界/权限/异常**：草稿无最小长度，发布≥200 字；自动关联书籍；已有书评可覆盖（草稿）；策略校验。

## 场景 14：评分与排序（Score & Ranking）

- 数据结构：ScoreEntry（用户对作品在某 realm 的 1-10 分，`package/contract/src/engagement/score.ts:8`–`14`）、ScoreAggregate（统计，`:49`–`59`）、ScoreRealmField（多维字段，`:80`–`89`）。

- 排序：聚合作为搜索/列表排序依据（`package/server/src/score/score.service.ts`、Meili 集成）。
- 端点：`POST /score`（`:23`–`40`）、`GET /score/unit/:unitId`（`:71`–`84`）、`/score/unit/:unitId/:realm`（`:88`–`101`）、`/score/user/:userId/:unitId`（`:105`–`118`）、`DELETE /score/:id`（admin，`:44`–`67`）、`POST /score/recalculate`（admin，`:122`–`147`）。

## Review vs Remark

| 特性 | Review | Remark |
|------|--------|--------|
| 存储 | Post(kind=REVIEW) | Post(kind=REMARK) |
| 最小长度 | 发布≥200 字 | 无 |
| 评分 | 有，创建 Score | 无 |
| 用途 | 深入书评 | 快速观感 |
| 入口 | `/review/new/$bookUnitId`、`/review/book/$bookId` | `/remark/book/$bookId`、内联表单 |
