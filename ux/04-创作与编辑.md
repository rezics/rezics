# 创作与编辑

从新建作品到发布的完整编辑工作流，覆盖书籍、章节、实体、摘录等内容类型，具备多用户协作、权限管理、修订历史与对比、草稿等能力。

## 场景 1：创作入口选择内容类型

**入口/触发**：点击导航/菜单的「创建」。

**前置条件**：已登录。

**步骤**：
1. 创建入口路由 — `package/app/src/routes/_mainLayout/create/index.tsx:1`–`11`。
2. `CreatePage` 展示创建选项面板 — `package/app/src/create/pages/CreatePage.tsx:29`–`98`。
3. 五个选项卡片：书籍/书架/领域/实体/投票 — `CreatePage.tsx:33`–`47`。
4. 点击跳对应创建流程（书籍→`/book/new`、实体→`/user/me/entity/new` 等）。

**关键数据流**：`/create/` → `CreatePage` → Link 跳转。

**边界/权限/异常**：无特殊校验；`shareTargetId` 支持从第三方应用直接创建。

## 场景 2：新建一本书籍

**入口/触发**：「新建书籍」或 `/book/new`。

**前置条件**：已登录。

**步骤**：
