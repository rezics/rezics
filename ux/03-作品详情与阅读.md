# 作品详情页与阅读体验

为用户提供完整的图书浏览、阅读、讨论与赏析功能：多语言/多版本内容呈现、逐章节/逐节点深度阅读、摘录管理与发现。

## 场景 1：打开书籍详情并查看基本信息

**入口/触发**：点击书籍卡片或搜索结果进入详情。

**前置条件**：bookId 已知；书籍存在；可选已设阅读语言。

**步骤**：
1. 详情主容器 `BookDetailLayout` — `package/app/src/routes/_mainLayout/book/$bookId/route.tsx:12` → `package/app/src/book-library/pages/BookDetailLayout.tsx:29`。
2. 调用 `bookQueries.detail(bookId,{languages,appLocale})` — `BookDetailLayout.tsx:37`–`42` → `package/api/src/book/book.queries.ts:30`。
3. 查询 `/book/:unitId` — `package/api/src/book/book.api.ts:37`–`56` → 后端 `bookService.getByUnitId()` — `package/server/src/book/book.service.ts:59`，返回含翻译/署名/许可的 DTO。
4. 重定向到 `/book/$bookId/info` — `package/app/src/routes/_mainLayout/book/$bookId/index.tsx:4`–`5`。
5. `BookBasicInfoPage` 渲染 — `package/app/src/book-library/pages/BookBasicInfoPage.tsx:28`–`129`：描述（Markdown，`:66`–`72`）、标签交互（`:82`–`98`，`package/api/src/tag/tag.queries.ts`）、署名（`package/app/src/book-library/sections/BookHeroSection.tsx:77`–`150`）、元数据面板（`package/app/src/book-library/components/BookDetail/MetadataPanel.tsx:18`–`88`）。

**关键数据流**：`/book/$bookId/info` → `BookBasicInfoPage` → `bookQueries.detail()` → `/book/:unitId` → `bookService.getByUnitId()` → 契约 `package/contract/src/book/book.ts`。

**边界/权限/异常**：bookId 不存在 → NotFound（`route.tsx:18`–`21`）；基本信息公开，编辑需所有者权限；多语言由 `useReadLanguageContext()`（`package/app/src/shared/hooks/useReadLanguageCandidates.ts:40`）提供。

## 场景 2：在详情页标签页间切换

**入口/触发**：点击标签栏不同标签。

**前置条件**：详情已加载。

**步骤**：
1. 标签栏（info/review/content/discussion/history）— `package/app/src/book-library/sections/BookDetailSection.tsx:77`–`107`。
2. 切换导航至对应路由：
   - info → `package/app/src/routes/_mainLayout/book/$bookId/info.tsx:8`（BookBasicInfoPage）
   - review → `book/$bookId/review.tsx:8`（BookReviewPage）
   - content → `book/$bookId/content.tsx:8`（BookContentPage）
   - discussion → `book/$bookId/discussion.tsx:4`（BookCommunityPage）
3. 各标签页独立侧边栏，经 `package/app/src/book-library/pages/bookDetailLayoutContext.ts` 传递。
4. 英雄区在所有标签页持续显示（`BookDetailLayout` 外壳）。

**关键数据流**：Tabs → 路由参数变更 → 对应页面 → 按需 API。

**边界/权限/异常**：小屏可横向滚动（`BookDetailSection.tsx:84`–`85`）；空标签显示占位（`BookVariantsPage.tsx:4`–`7` 目前返回 null）。

## 场景 3：查看正文结构与章节目录

**入口/触发**：点击「目录/content」标签。

**前置条件**：书籍有章节；内容结构已建立。

**步骤**：
1. `/book/$bookId/content` → `BookContentPage` — `package/app/src/book-library/pages/BookContentPage.tsx:37`–`74`。
2. `bookQueries.contentStructure(bookId)` — `package/api/src/book/book.queries.ts:113`–`118`。
3. `/book/:unitId/content-structure` — `package/server/src/book/book.api.ts:74`–`85`。
4. `bookService.getContentStructureByBookUnitId()` 返回树状结构 — `package/server/src/book/book.service.ts`。
5. `ChapterList` 虚拟滚动目录树 — `package/app/src/book-library/components/Chapter/ChapterList.tsx:47`–`100`：可展开/折叠（`:21`），节点链接 `/book/$bookId/node/$nodeId`（`:61`–`65`）。
6. 侧栏统计字数/页数 — `ChapterList.tsx:13`–`34`。

**关键数据流**：`/book/$bookId/content` → `BookContentPage` → `contentStructure()` → `/book/:unitId/content-structure` → `getContentStructureByBookUnitId()` → 契约 `package/contract/src/content/structure.ts`。

**边界/权限/异常**：结构为空显示加载/空态（`:60`）；仅显示有权访问的节点（后端 `package/server/src/unit/publication-policy.ts`）。

## 场景 4：进入节点/章节阅读器

**入口/触发**：从目录点击章节节点或直链。

**前置条件**：nodeId 已知；内容单元存在；有权访问。

**步骤**：
1. `/book_/$bookId/node/$nodeId/` → `BookReadNodePage` — `package/app/src/routes/book_/$bookId/node/$nodeId/index.tsx:8`。
2. `BookReadNodePage` 解析参数 — `package/app/src/book-read-node/sections/BookReadNodePage.tsx:5`–`10` → `BookReadNodeSection`。
3. `BookReadNodeSection` — `package/app/src/book-read-node/sections/BookReadNodeSection.tsx:18`–`100`：`bookQueries.detail`（`:24`–`29`）、`contentStructure`（`:31`–`34`）、`resolveNodeView()`（`:37`–`41`）、可读时 `chapterDetailQuery(contentUnitId)`（`:47`–`49`）。
4. 按状态渲染：`ReadingNodeView`/`DeletedNodeView`/`EmptyNodeView`（`package/app/src/book-read-node/components/`）。

**关键数据流**：`/book_/$bookId/node/$nodeId/` → `BookReadNodePage` → detail+contentStructure+chapterDetail → `bookService`/`chapterService` → 契约 `package/contract/src/book/chapter.ts`。

**边界/权限/异常**：节点不存在 404（`:55`–`56`）；删除态（`:58`–`72`）；编辑权限 `useCanEdit()`。

## 场景 5：切换多语言版本阅读

**入口/触发**：详情或阅读时选择不同语言。

**前置条件**：书有多语言翻译；已设阅读语言。

**步骤**：
1. `useReadLanguageContext()` 提供全局语言上下文 — `package/app/src/shared/hooks/useReadLanguageCandidates.ts:40`–`100`：`userQueries.settings()`（`:43`–`47`）、`useLocale()`（`:41`）、`uniqueLanguages()`（`:19`–`28`）。
2. `BookDetailShell` 用 `useBookLanguage(bookId,bookInfo)` 选语言 — `package/app/src/book-library/sections/BookDetailSection.tsx:56`–`61`。
3. 语言变化更新查询参数 — `BookBasicInfoPage.tsx:41`–`43`。
4. 后端 `resolveEffectiveReadLanguageInput()` 解析 — `package/server/src/book/book.api.ts:41`–`45`。
5. 按 `selectedLang/languages` 渲染翻译。

**关键数据流**：语言选择 → `useReadLanguageContext()` → 查询参数 → 后端语言解析 → 翻译 → UI。

**边界/权限/异常**：未登录用浏览器 locale + app locale（`:42`）；偏好持久化 localStorage（`:52`–`58`）；`normalizeLanguage()`（`package/contract/src/translation/language-resolution.ts`）。

## 场景 6：在作品内搜索

**入口/触发**：详情页搜索框/标签输入关键词，限定该书范围。

**前置条件**：书已索引；输入关键词。

**步骤**：
1. `/book/$bookId/search?q=...&category=...` — `package/app/src/routes/_mainLayout/book/$bookId/search.tsx:44`–`53`。
2. `validateSearch()` 解析参数 — `search.tsx:45`–`51`。
3. `BookScopedSearchPage` 设置 scope `{kind:"book",unitId}` — `search.tsx:24`–`27`，调用 `FederatedSearchPage`（`package/app/src/search/pages/FederatedSearchPage.tsx:57`–`100`）。
4. Meili 后端 — `package/server/src/meili/content/content.api.ts`。
5. `FederatedResultList` 显示各类结果 — `package/app/src/search/components/FederatedResultList.tsx`。

**关键数据流**：输入 → URL → `FederatedSearchPage` → Meili → 分类结果 → UI。

**边界/权限/异常**：仅公开内容；分类切换 all/特定（`search.tsx:30`–`39`）；搜索历史 `useSearchHistory()`（`package/app/src/search/hooks/useSearchHistory.ts`）。

## 场景 7：查看作品评论与评分

**入口/触发**：点击「评论/评分」标签。

**前置条件**：有评分/评论；有查看权限。

**步骤**：
1. `/book/$bookId/review` → `BookReviewPage` — `package/app/src/book-library/pages/BookReviewPage.tsx:28`–`134`。
2. 查询书籍详情（`:32`–`38`）、评论列表 `postQueries.list(...)`（`:45`–`65`）、评分 `ScoreOverview`（`:69`–`74`，`package/api/src/score/score.queries.ts`）。
3. 显示 `ShelfByBookPreview`（`:97`–`102`）、`ReviewList`（最多 5 条，`:130`）、写评论按钮跳 `/review/new/$bookUnitId`（`:111`–`129`）。
4. discussion 标签 → `BookCommunityPage` — `package/app/src/book-library/pages/BookDiscussionPage.tsx:35`–`85`：`ReplyComposer`（`:63`–`67`）、`FeedSection`（`:71`–`82`）。

**关键数据流**：`/book/$bookId/review` → `BookReviewPage` → `postQueries.list()` + score → post/score 服务 → 契约 `package/contract/src/realm/community.ts`。

**边界/权限/异常**：评论需登录；仅公开评论；评分聚合由 `scoreService.getAggregatesByUnit()`（`package/server/src/score/score.service.ts`）计算。

## 场景 8：浏览并管理摘录（按书）

**入口/触发**：点击「摘录」链接或访问 `/excerpt/book/$bookId`。

**前置条件**：有关联摘录；可访问公开摘录。

**步骤**：
1. `/excerpt/book/$bookId` → `ExcerptByBookPage` — `package/app/src/routes/_mainLayout/excerpt/book/$bookId.tsx:8`。
2. `ExcerptByBookPage` — `package/app/src/excerpt/pages/ExcerptByBookPage.tsx:9`–`23`：标题（`:14`–`16`）、创建表单 `ExcerptNewPage`（`:17`）、`UnitsPage`（type="QUOTE", targetUnitId=bookId，`:18`–`20`）。
3. 点击单条 → `/excerpt/$unitId` → `ExcerptPage` — `package/app/src/excerpt/pages/ExcerptPage.tsx:5`–`17`。
4. `ExcerptDetailSection` 显示文本/元数据/标签/评论 — `package/app/src/excerpt/sections/ExcerptDetailSection.tsx`。

**关键数据流**：`/excerpt/book/$bookId` → `ExcerptByBookPage` → `UnitsPage`(QUOTE) → unit 服务 → 契约 `package/contract/src/unit/unit.ts`。

**边界/权限/异常**：仅公开摘录；可创建/编辑自己的摘录；摘录须关联有效章节。

## 场景 9：查看来源/外部引用与系列归属

**入口/触发**：基本信息页查看来源证据/外部引用/所属系列。

**前置条件**：已配置来源/外部链接/系列关系。

**步骤**：
1. `MetadataPanel` 显示基础元数据 — `package/app/src/book-library/pages/BookBasicInfoPage.tsx`。
2. `BookHeroSection` 显示署名与来源 — `package/app/src/book-library/sections/BookHeroSection.tsx:77`–`150`：封面（`:106`）、CREDIT_ROLES（`:55`–`75`）、`SourceEvidencePreview`（`package/app/src/book-library/components/SourceEvidencePreview.tsx:35`–`100`）。
3. 外部引用由 `unitExternalRefService` 提供 — `package/server/src/unit-external-ref/unit-external-ref.service.ts`。
4. 系列归属由 `seriesDataIntegration` 管理 — `package/app/src/series-integration/seriesDataIntegration.ts`（**进行中/stub**，见 `package/app/src/series-integration/index.ts`）。

**关键数据流**：书籍 DTO(`creditAttribution`) → 英雄区/侧栏 → `SourceEvidencePreview` → 外部链接（契约 `package/contract/src/unit/external-ref.ts`）。

**边界/权限/异常**：有配置才显示；外部链接需确认跳转；系列功能开发中。

## 场景 10：查看作者与创作者署名

**入口/触发**：英雄区或章节中查看作者。

**前置条件**：已配置署名；创作者账号存在。

**步骤**：
1. `BookHeroSection` 展示署名 — `package/app/src/book-library/sections/BookHeroSection.tsx:77`–`150`：遍历 CREDIT_ROLES（`:55`–`75`）、从 `creditAttribution` 取实体（`:120`–`130`）。
2. 点击署名跳作者资料 — `package/app/src/book-library/components/AuthorInfo.tsx:43`–`48`。
3. `AuthorInfo` 展示头像/名称/简介/`FollowButton`（`:64`–`71`）/编辑（仅本人，`:53`–`55`）— `package/app/src/book-library/components/AuthorInfo.tsx:169`–`207`。

**关键数据流**：书籍 DTO `creditAttribution` → 英雄区 → `SourceEvidencePreview`/`AuthorInfo` → 用户资料页 → 契约 `package/contract/src/unit/unit.ts`。

**边界/权限/异常**：署名实体可为用户或非用户实体；编辑权限限署名本人或书籍所有者。

## 场景 11：查看单条摘录详情

**入口/触发**：摘录列表点击或分享链接。

**前置条件**：unitId 已知；公开。

**步骤**：
1. `/excerpt/$unitId` → `ExcerptPage` — `package/app/src/routes/_mainLayout/excerpt/$unitId/index.ts`。
2. `ExcerptPage` → `ExcerptDetailSection` — `package/app/src/excerpt/pages/ExcerptPage.tsx:5`–`17`。
3. `ExcerptDetailSection` 查询摘录元数据/内容 — `package/api/src/excerpt/excerpt.queries.ts` + 关联书/章。
4. 显示高亮源文本、创建者、标签、评论、返回链接。

**关键数据流**：`/excerpt/$unitId` → `ExcerptPage` → `ExcerptDetailSection` → excerpt 查询 → unit/excerpt 服务 → 契约 `package/contract/src/unit/unit.ts`。

**边界/权限/异常**：仅公开摘录；源章节删除显示占位。

## 场景 12：查看作品阅读进度（详情侧）

**入口/触发**：详情页或书架查看该作品进度。

**前置条件**：已登录；已加入书架；有进度记录。

**步骤**：
1. `BookReviewPage` 显示 `ShelfByBookPreview` — `package/app/src/book-library/pages/BookReviewPage.tsx:97`–`102`，调用 `package/api/src/progress/progress.queries.ts`。
2. 进度由 `progressService` 管理 — `package/server/src/progress/progress.service.ts`（`getByUserAndUnit()` 等；字段 `currentNodeId`/`currentPosition`/`completedAttempt`）。
3. 可更新状态（想读/在读/已读）。

**关键数据流**：登录 → `progressQueries.getByUserAndUnit()` → `/progress/...` → 契约 progress 模型。

> 进度的完整创建/管理流程见 [章节 08](./08-书架收藏进度.md)。

**边界/权限/异常**：进度私密；未登录不能记录；完整进度 UI 集成 **TODO**（当前为预览组件）。
