# 书架、收藏、阅读进度与书架浏览

整合四个特性：**书架（Shelf）** 用户创建的单元容器、**收藏（Collection）** 将单元保存到书架的操作、**阅读进度（Progress）** 追踪阅读状态、**书架浏览（Bookshelf View）** 多种可视化布局。

## 数据模型澄清

- **Shelf**：`Unit` 的一种（unitType="shelf"），含 `ShelfItem`（引用 unit 或 comment），item 可有 children（reviews/comments/tags）；系统书架（Favorites/Saved/Backlog/Active/Completed）由后端自动创建。
- **Collection**：不是独立类型，而是「建 ShelfItem + 应用元数据」的操作抽象（`POST /collect`）；`/collect/status` 投影查询「单元在哪些书架」；进度书架（Backlog/Active/Completed）不能经 Collect 直接编辑，由 Progress 副作用创建。
- **Progress**：独立 `UserUnitProgress` 行，与 shelf 无直接关联（标记 ACTIVE/BACKLOG/COMPLETED 可副作用创建对应进度书架项）；进度库为聚合视图。
- **BookshelfView**：纯 UI 组件库，消费 `BookshelfItem[]`，与 shelf/collection/progress 无数据依赖。
- 三者**未**统一到 Unit/Subscription：Shelf 是 Unit，Collection 操作 ShelfItem 表，Progress 独立表，Subscription 为另一系统（关注，见 [章节 01](./01-认证与账户.md)）。

## 权限与异常

- 创建/收藏/标记进度：已登录；编辑/删除书架：所有者或有权限；查看私密书架/系统书架：所有者；查看他人进度库：仅公开账户。
- 404（不存在）/403（无权/私密）/400（无效输入）/409（无 slug 建系统书架）/PolicyDenial（`PolicyDenialNotice`）。

## 关键实现亮点

分数索引（`package/server/src/shelf/fractional-index.ts`）；cursor 分页；视图持久化 `shelf.extra.viewMode`；CollectionModal 过滤进度书架（`CollectionModal.tsx:38`–`42`）；`useHydratedShelfItems()` 懒加载补充；React Query `invalidateQueries`/`setQueryData` 一致性。
