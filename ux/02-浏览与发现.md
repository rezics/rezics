# 目录浏览与发现

本簇覆盖浏览首页信息流、书/游戏/媒体库、执行全局与按类型搜索、通过标签与实体页进行内容发现的所有用户场景。

## 场景 1：浏览首页信息流与分页

**入口/触发**：访问首页 `/` 或刷新。

**前置条件**：可登录可不登录（未登录浏览公开内容）。

**步骤**：
1. 首页路由懒加载页面 — `package/app/src/routes/_mainLayout/index.tsx:1`–`7` → `package/app/src/home/pages/Home.tsx:17`。
2. Home 挂载 FeedLayout/FeedSection，初始化 scope='home'、sort='best' — `Home.tsx:50`–`52`。
3. FeedSection 用 `feedRowsInfiniteQuery` 请求信息流行 — `package/app/src/feed/sections/FeedSection.tsx:35`。
4. API 请求 `/feed/rows` — `package/api/src/feed/feed.api.ts:5`–`8`。
5. 后端 feedApi 解析参数并调用 feedService.list — `package/server/src/feed/feed.api.ts:7`–`28`。
6. feedService 聚合 post 数据、应用排序（hot/best/new/top/rising）、注入 carousel 行 — `package/server/src/feed/feed.service.ts:24`–`44`。
7. 返回 FeedResponse（rows + nextCursor）— `package/contract/src/feed/feed.ts:107`–`114`。
8. 显示内容卡片，支持「加载更多」/「到底」— `FeedSection.tsx:40`–`85`。

**关键数据流**：`index.tsx` → `Home.tsx` → `FeedSection.tsx` → `feed.queries.ts:13`–`24`（infiniteQueryOptions）→ `feed.api.ts:5`–`8` → `feed.api.ts:7`–`28`（后端）→ `feed.service.ts` → 契约 `feed.ts`。

**边界/权限/异常**：空态 `end_of_list`（`FeedSection.tsx:78`–`82`）；加载 Spinner（`:44`）；错误 `QueryErrorDisplay`（`:38`）；未登录 viewerUserId 为 null，管理员可见内部行（`feed.api.ts:9`–`17`）。

## 场景 2：浏览书籍库、按类型过滤与排序

**入口/触发**：导航点击「Books」进入 `/book/` 或 `/book/search`。

**前置条件**：可登录可不登录；按用户允许分级显示。

**步骤**：
1. 路由加载 BookLibPage — `package/app/src/routes/_mainLayout/book/index.tsx:1`–`10`、`book/search.tsx:1`–`18`。
2. BookLibPage 读取 URL 标签/关键词、注入允许分级 — `package/app/src/book-library/pages/BookLibPage.tsx:30`–`66`。
3. `useLocalizedContentSearch`（type=["BOOK"]）发起 Meili 搜索 — `BookLibPage.tsx:77`–`82`。
4. `contentSearchQueryOptions` 发 `POST /meili/content/search` — `package/api/src/meili/meili.queries.ts:34`–`39`。
5. 后端接收 ContentSearchOptions，应用分级过滤 — `package/server/src/meili/content/content.api.ts:10`–`30`。
6. contentService 检索 BOOK 文档 — `package/server/src/meili/content/content.service.ts:40`–`100+`。
7. 返回 ContentSearchResult（items+total）— `package/contract/src/meili/content.ts`。
8. 映射 ContentSearchDocument→BookDTO，支持排序（time/rating）与分页 — `BookLibPage.tsx:114`–`182`。
9. `BookLibSection` 渲染卡片列表与分页工具栏 — `package/app/src/book-library/sections/BookLibSection.tsx`。

**关键数据流**：`book/index.tsx` → `BookLibPage.tsx` → `meili.queries.ts:34`–`39` → `meili.api.ts:30`–`38` → `content.api.ts:10`–`30` → `content.service.ts` → 契约 `meili/content.ts`、`search/search.ts`。

**边界/权限/异常**：`useAllowedRatings` + `intersectRatings` 过滤（`BookLibPage.tsx:55`–`59`、`content.api.ts:17`–`18`）；空态 `end_of_list`；语言自动应用 preferred/all（`BookLibPage.tsx:69`–`92`）。

## 场景 4：全局搜索与分类搜索

**入口/触发**：访问 `/search`，输入关键词或选分类。

**前置条件**：无。

**步骤**：
1. GlobalSearchPage — `package/app/src/routes/_mainLayout/search/index.tsx:16`–`51`。
2. 解析 URL（q、category）— `search/index.tsx:55`–`61`。
3. FederatedSearchPage 管理本地 query/category — `package/app/src/search/pages/FederatedSearchPage.tsx:57`–`93`。
4. `useLocalizedFederatedSearch` 请求联邦搜索 — `FederatedSearchPage.tsx:89`–`93`。
5. 后端 `/meili/search`（或分类端点）调用 federation API — `package/server/src/meili/meili.api.ts`。
6. meiliService 按 category 分发到对应索引（books/posts/comments/realms/users/entities）— `package/server/src/meili/meili.service.ts`。
7. 返回 FederatedSearchResult（grouped/ranked/single）— `package/contract/src/search/federated.ts:109`–`136`。
8. `FederatedResultList` 按 kind 渲染 — `package/app/src/search/components/FederatedResultList.tsx`。
9. 点击结果跳转详情（book/post/entity 等）。

**关键数据流**：`search/index.tsx` → `FederatedSearchPage.tsx` → 联邦搜索 hook → `meili.api.ts:65`–`200+` → `meili.service.ts` → 契约 `search/federated.ts`、`search/search.ts`。

**边界/权限/异常**：空查询显示各类别占位（待验证）；空结果显示 no results；分类切换更新 URL 驱动刷新（`search/index.tsx:30`–`38`）。

## 场景 5：标签聚合页（slug 与 unitId 双入口）

**入口/触发**：点击标签，或访问 `/t/:tagSlug`、`/tag/:unitId`。

**前置条件**：标签 Unit 存在且有访问权限。

**步骤**：
1. Slug 入口 `/t/$tagSlug` loader 调用 slug 解析 — `package/app/src/routes/_mainLayout/t/$tagSlug.tsx:5`–`17`。
2. `isPublicTagSlugRouteParams` 校验格式 — `$tagSlug.tsx:7`。
3. `slugApi.resolve` 发 `POST /slug/resolve`（scope='tag'）— `package/api/src/slug/slug.api.ts:15`–`20`。
4. 后端按 scope 映射 slugScope 查 Unit — `package/server/src/slug/slug.api.ts:22`–`47`。
5. 返回 `{unitId,type}`，重定向 `/tag/$unitId` — `$tagSlug.tsx:12`–`15`。
6. UnitId 入口加载 TagUnitPage — `package/app/src/routes/_mainLayout/tag/$unitId.tsx:1`–`10`。
7. `tagQueries.detail(unitId)` — `package/app/src/tag/pages/TagUnitPage.tsx:9`–`12`。
8. `GET /tag/:unitId` — `package/api/src/tag/tag.queries.ts:24`–`29`。
9. 后端 tagApi.get 返回 UnitTagDTO — `package/server/src/tag/tag.api.ts`。
10. 渲染 TagDetailCard — `package/app/src/tag/components/TagCards.tsx`。

**关键数据流**：`t/$tagSlug.tsx` →（slug 解析 `slug.api.ts:15`–`20` → `slug.api.ts:22`–`47`）→ `/tag/$unitId` → `TagUnitPage.tsx` → `tag.queries.ts:24`–`29` → `tag.api.ts`/`tag.service.ts`；契约 `slug/slug-ref.ts`、`slug/by-slug.ts`、`tag`。

**边界/权限/异常**：slug/unitId 未找到触发 404（`$tagSlug.tsx:7`）；加载态消息（`TagUnitPage.tsx:13`–`20`）。

> 进阶：按书/域的标签子树 `tag/book/$bookId/**`、`tag/domain/$unitId/**` 提供更细的标签浏览，结构同上（slug/id 解析 + 详情）。

## 场景 9：标签搜索与自动完成

**入口/触发**：在搜索/编辑器中输入标签关键词。

**前置条件**：无。

**步骤**：
1. 标签搜索输入框（SearchFilter/TagSelector）。

## 场景 10：语言/主题切换对浏览的影响

**入口/触发**：切换应用语言/主题。

**前置条件**：应用已打开。

**步骤**：
1. 语言切换更新候选 — `package/app/src/shared/hooks/useReadLanguageCandidates.ts`。
2. 使用本地化搜索的页面自动重搜（传 languages/appLocale/languageMode）— `BookLibPage.tsx:88`–`92`。
3. 后端按语言过滤返回对应翻译 — `package/server/src/meili/content/content.service.ts`。
4. 主题切换仅影响 CSS，无需重查。
5. 组件用新语言 i18n 文本重渲（`useTranslation`）。

**关键数据流**：全局设置 → 搜索/查询参数（languages/appLocale）→ `content.service.ts` → 契约 `meili/content.ts`。

**边界/权限/异常**：不支持的语言回退默认/英文（`BookLibPage.tsx:69`）。
