## Why

Rezics needs a first-class way to label whether a Unit's public-facing content
was created, assisted, or substantially generated by AI. The existing
`ContentRating` field answers audience suitability; overloading it for AI usage
would mix provenance disclosure with age/sensitivity filtering.

## What Changes

- Introduce a Unit-level AI disclosure mode that records the declared degree of
  AI involvement for catalog and content Units.
- Define canonical disclosure modes for no AI use, AI-assisted human work,
  AI-originated work with human editing/review, primarily machine-generated
  work, and unknown provenance.
- Keep AI disclosure independent from `ContentRating`; rating filtering and
  opt-ins continue to operate unchanged.
- Allow optional supporting metadata for model/provider/review/source details
  without making those details required for every Unit.
- Expose the new disclosure through contracts, server persistence, search/index
  surfaces, and frontend display/edit flows where Unit metadata is already
  shown or maintained.
- No breaking API changes are intended; existing clients that ignore the new
  optional field should continue to work.

## Capabilities

### New Capabilities

- `unit-ai-disclosure`: Unit-level declaration and exposure of AI content
  involvement/provenance.

### Modified Capabilities

- `content-rating`: Clarify that AI disclosure does not change rating semantics,
  ordering, or allowed-rating filtering.

## Impact

- Affected packages:
  - `package/contract`: shared enum/schema/DTO additions for AI disclosure.
  - `package/server`: Prisma schema, migrations, Unit mapping/services, Book or
    other Unit-facing APIs, and search indexing.
  - `package/app`: metadata editor/display surfaces and search/filter UI where
    appropriate.
  - `package/ui`: shared badge/selector components if the app needs reusable
    presentation.
- Database migration:
  - Add nullable/defaulted AI disclosure fields to `Unit` or an adjacent
    Unit-owned metadata shape.
  - Backfill existing Units to a conservative default that does not assert AI
    involvement.
- Search/indexing:
  - Include disclosure mode in content search documents if Units can be filtered
    or badged from search results.
- Backward compatibility:
  - Existing APIs remain valid.
  - New fields are optional in responses and inputs unless a specific create or
    update flow chooses to expose them.
