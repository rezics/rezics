# Radius

`md` (8px) is the MUI `shape.borderRadius` default and the rezics workhorse. Source: `package/ui/src/config/tokens/radius.ts`.

## Mapping

| Element | Token |
| --- | --- |
| Inputs, badges, chips | `xs`–`sm` |
| Buttons, tags | `sm` |
| Cards, panels, default | `md` |
| Modals, large surfaces | `lg`–`xl` |
| Hero / feature sections | `2xl` |
| Pill buttons, status pills | `pill` |
| Avatars, circular badges | `full` |

## Usage

```tsx
// MUI — shape.borderRadius default is `md` (8px)
<Card>  // borderRadius: 8 by default
<Box sx={{ borderRadius: 1 }}>  // theme.shape.borderRadius * 1

// UnoCSS — utilities resolve through theme.borderRadius
<div className="rounded-md">  // 8px

// TS source (rare — only if generating CSS outside MUI/UnoCSS)
import { radius } from "@rezics/ui/config/tokens/radius";
```

Avoid mixing radii within a single composition — if the parent card is `md`, child elements should be `xs` or `sm`, never larger than the parent.
