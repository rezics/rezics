# Spacing

8px base scale. `theme.spacing(1) === 8px` in MUI; tokens align 1-to-1. Source: `package/ui/src/config/tokens/spacing.ts`.

Use multiples of the scale; never raw pixel values. The scale is intentionally coarse — if you need a value between two steps, that's a signal to reconsider the layout.

## Common patterns

| Use | Token |
| --- | --- |
| Inline icon-to-label gap | `2` (8px) |
| Form field row gap | `3` (12px) |
| Card padding | `4` (16px) |
| Section gap | `5`–`6` (24–32px) |
| Page-level vertical rhythm | `8`–`12` (48–96px) |

## Usage

```tsx
// MUI sx — pass numeric step (auto × theme.spacing == 8px)
<Stack spacing={3} sx={{ p: 4 }}>
<Box sx={{ mt: 5, gap: 2 }}>

// CSS variables
.row { padding: var(--rezics-space-4); gap: var(--rezics-space-2); }

// UnoCSS (shadcn preset uses 4-based scale; rezics theme overrides to 8-based)
<div className="p-4 gap-2">  // 16px / 8px
```

Don't introduce off-grid values. If 12px feels right but the next step (24px) feels too big, the spacing rhythm of the surrounding section is probably wrong, not the scale.
