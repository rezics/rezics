# Typography

Foundation v1 typography. Source: `package/ui/src/config/tokens/typography.ts`. Sizes are `clamp()`-based viewport scales — they fluidly respond between min and max breakpoints.

## Families

Stacks live in `tokens/typography.ts` and are wired into MUI (`theme.typography.fontFamily`) and UnoCSS (`theme.fontFamily.{sans,serif,mono}`).

- **Sans** (`font-sans` / MUI default) — Inter + Source Han Sans (CJK auto-routed by `:lang()`). Default UI, body, headings.
- **Serif** (`font-serif`) — Source Serif 4 + Source Han Serif. Reader / longform prose.
- **Mono** (`font-mono`) — CaskaydiaMono Nerd Font + Sarasa Mono. Code, IDs, technical metadata.

The CJK fallback inside each stack is the only piece that lives in CSS (`--font-sans-cjk` / `--font-serif-cjk`), so it can re-route per `:lang()` — SC for `zh-Hans`/`zh-CN`, JP for `ja`, KR for `ko`, TC default.

## Weights

Three weights only. Heavier weights are out of scope to keep the parchment-archive feel (see `voice.md`).

| Token | Value | Use |
| --- | --- | --- |
| `regular` | 400 | Body, default |
| `medium` | 500 | Emphasis, labels, lead body |
| `semibold` | 600 | Headings (xl–3xl) |

## Line heights

| Token | Value | Use |
| --- | --- | --- |
| `reader` | 1.6 | Longform prose (serif) |
| `body` | 1.55 | Standard paragraph copy |
| `ui` | 1.4 | Buttons, inputs, labels |
| `dense` | 1.3 | Headings, table rows |

## Letter spacing

| Token | Value | Use |
| --- | --- | --- |
| `tight` | -0.01em | Display headings |
| `normal` | 0 | Body |
| `wide` | 0.02em | All-caps labels, eyebrows |

## font-size-adjust

Inter's x-height is normalized to ~52.2% via `font-size-adjust: ex-height 0.522` so the Latin run matches Source Han Sans optical baseline when the two fall back to each other in mixed CJK content. Without this, mixed text shows uneven baselines.

## Reference

> **Apple HIG typography**: developer.apple.com/design/human-interface-guidelines/typography — rezics adopts the simpler label hierarchy and CJK baseline sensitivity, but keeps a compact project scale instead of mirroring the full Dynamic Type matrix.
