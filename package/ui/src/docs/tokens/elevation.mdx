# Elevation

**Default policy is borderless.** Surfaces separate via whisper borders or surface-color shifts, *not* shadows. Shadows are reserved for the modal tier and a small set of true float-above-canvas surfaces. Source: `package/ui/src/config/tokens/elevation.ts`.

This keeps the parchment-archive feel — the page is calm, layers are quiet, and elevation is something you only feel when it really means *I am temporarily on top*.

## When to use what

| Tier | Token | Use |
| --- | --- | --- |
| flat (default) | none | Cards, panels, sections — separate via `border-whisper` |
| 1 | `--shadow-1` | Sticky bars, hover-lift micro affordance |
| 2 | `--shadow-2` | Dropdowns, popovers |
| 3 | `--shadow-3` | Floating action menus |
| modal | `--shadow-modal` | Modals, dialogs, full overlays |

Dark mode shadows scale up opacity (×5) so they stay perceptible against deeper canvas tones.

## Usage

```tsx
// MUI sx — radius via theme.shape, color/shadow via CSS vars
<Box sx={{
  borderRadius: 1.5,                                 // theme.shape.borderRadius * 1.5
  background: "var(--colors-surface-elevated)",
  boxShadow: "var(--shadow-modal)",
}}>

// UnoCSS — utilities resolve through theme
<div className="rounded-lg bg-surface-elevated shadow-modal">
```

Don't reach for `shadow-2` to "make a card stand out" — that's what surface tokens (`base` vs `elevated`) and whisper borders are for. Shadows for hierarchy is a Material-2 reflex; rezics is closer to Material-3 + Apple in temperament.

## Reference

> **Apple HIG materials and MD3 elevation**: developer.apple.com/design/human-interface-guidelines/materials and m3.material.io/styles/elevation/overview — rezics adopts tonal separation for in-flow depth and reserves shadow for modal-tier surfaces.
