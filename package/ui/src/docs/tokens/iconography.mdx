# Iconography

rezics' default icon library is **lucide-react** — a community fork of Feather, with a stroke style that reads on the plain canvas without the geometric stiffness that MUI's filled defaults imposed. When lucide lacks a glyph, fall back to **`@tabler/icons-react`** with clear naming that makes the fallback obvious in code. Apple SF Symbols is the deeper reference for stroke weight + scale sensibility; we adopt the philosophy at lower fidelity.

## Standard sizes

rezics uses three icon sizes only. Bigger or smaller is a sign you're carrying decoration that doesn't earn the space.

| Size | Use |
| --- | --- |
| `16px` | Inline with body text. Inline badges, list bullets, breadcrumb separators. |
| `20px` | Buttons, list items, toolbars, navigation. The default for interactive chrome. |
| `24px` | Page headers, empty-state icons, card hero glyphs. Reserved for moments that anchor the layout. |

Density does **not** affect icon size. A compact-density list keeps its 20px icons; only padding and gap shrink.

## Stroke + color

lucide ships a `2px` stroke that sits well at all three sizes. Don't override `strokeWidth` per icon — that breaks visual consistency with the rest of the system. Color follows the surrounding text role (`currentColor`); never hard-code hex.

## Named fallback: `@tabler/icons-react`

If lucide lacks a glyph (rare; tabler covers ~5,000), import from `@tabler/icons-react` with the `Tabler*` prefix or an explicit import rename to make the cross-library origin visible at the import site:

```tsx
import { IconBrandGitlab as GitLabLogo } from "@tabler/icons-react";
```

Avoid mixing libraries inside a single feature folder if a lucide-only solution exists. The named-fallback rule keeps cross-library use grep-able.

## Reference

> Apple's SF Symbols ships **9 weights × 3 scales × 4 rendering modes** with glyph-level inflection points across the entire library — the deepest icon system in any platform UI kit. rezics adopts the underlying sensibility (consistent stroke, three sizes, color follows text role) at lucide's lower fidelity (2px stroke, single rendering mode). MD3 ships Material Symbols at 5 weights × 3 sizes; we don't use them because the geometric Roman style reads as Material brand against rezics chrome. Apple source: developer.apple.com/sf-symbols. lucide source: lucide.dev. Tabler source: tabler-icons.io.
