# Colors

Rezics uses a hybrid color model: brand red carries product identity and primary
actions; blue carries textual navigation. The page baseline is plain white in
light mode and plain black in dark mode. Avoid custom page tints.

Use the Storybook **Mode** toolbar to switch this page between light and dark.
Each swatch below renders the value for the active mode and lists both mode
values in its metadata.

## Interaction States

Primary controls use brand tones. Text links stay `#1a73e8`; hover reveals
affordance with underline instead of changing hue. Focus stays brand-led so
keyboard navigation still feels like Rezics even when the label is blue.

<Unstyled>
  <FutureInteractionStates />
</Unstyled>

Disclosure controls are a component-level trial: the closed affordance can use
brand because it invites opening content; the open control can use blue because
it behaves like a secondary text action. The actual `Collapsible` rewrite should
validate this against the component's real states and labels.

## Reading Rule

Contrast numbers are diagnostics, not a blanket veto. The rule is about reading
load:

```txt
Long content / posts / review body     -> neutral text
Inline markdown links / URLs           -> link blue
Primary action / selected indicator    -> brand red
Logo / REZICS word / accent bar        -> brand red
Semantic status                        -> semantic role
```

Brand red is allowed in short, stable UI chrome and brand text. It should not be
used for large bodies of user-generated or frequently changing content because
that is where color fatigue accumulates.

## Usage

```tsx
<button className="bg-brand-fill hover:bg-brand-fill-hover active:bg-brand-fill-active text-text-on-brand">
  Add to Library
</button>

<TextLink className="text-link hover:underline">
  View all editions
</TextLink>

<article className="bg-surface-canvas text-text-primary">
  Long-form content stays neutral.
</article>
```

Runtime callsites should consume tokens, not hardcoded hex values. Hex values
belong in the token source and design documentation only.
