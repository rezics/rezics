# Colors

Foundation v1 color tokens. Source of truth: `package/ui/src/config/tokens/colors.ts` → `package/ui/src/shared/styles/layers.css` (CSS custom properties) → MUI theme palette. **Always reference tokens, never raw hex.**

Mode switch: `<html data-theme="dark">`. Toolbar 🎨 globe at top-right toggles preview between light and dark.

## Surface

Layered backgrounds, light → dark in stack order. Default canvas is parchment-warm in light mode.

## Usage

```tsx
// MUI sx
<Box sx={{ bgcolor: "var(--rzc-color-surface-elevated)", color: "var(--rzc-color-text-primary)" }}>

// UnoCSS (presetWind4 + theme tokens)
<div className="bg-surface-base text-primary border-b border-whisper">

// Raw CSS
.card { background: var(--rzc-color-surface-base); }
```

Never hardcode `#1d1d1f` or `#f4606c` — always go through tokens so light/dark and AA-safe variants resolve correctly.
