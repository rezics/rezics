# Colors

Foundation v1 color tokens. Source of truth: `package/ui/src/config/tokens/colors.ts` (`lightColors` and `darkColors`); UnoCSS preset-wind4 emits each leaf as a flat `--colors-*` custom property under `:root, :host`, and the `.dark { --colors-*: … }` override is generated by a preflight in `uno-config.ts`. **Always reference tokens, never raw hex.**

Mode switch: `<html class="dark">`. Use the **Mode** toolbar item (sun/moon) at the top of Storybook to toggle preview between light and dark — every contrast badge re-measures live.

The badge format is `vs <target> · <ratio> · <tier>`. For surface tokens it tests "body text on this surface"; for text tokens "this text on the default surface"; for brand/semantic/sentiment fills "on-brand text on this fill". Border tokens carry no text, so contrast is omitted.

Layered backgrounds, light → dark in stack order. Default canvas is parchment-warm in light mode.

## Sentiment — 正負極性

Vote / rating / poll 的正負極性配色。`positive` 直接共享品牌轮回红——投票、評分都和品牌情緒同步；`negative` 採用降飽和的板岩藍（slate-blue），冷靜、不嗆，避免與品牌紅或 `info` 競爭。

應用：upvote / 評分 ≥ 5 / approve = positive · downvote / 評分 < 5 / reject = negative。`*-text` 變體會依模式自動切換為 AA-safe 的深/淺色。Fill 變體 badge 測 on-brand text 對 fill；text 變體 badge 測 text 對預設 surface。

## Border

Whisper is the workhorse — used for borderless-feel section separation. Defined for input boundaries; strong reserved for emphasis. Border tokens don't carry text, so no contrast badge is rendered.

## Usage

```tsx
// MUI sx
<Box sx={{ bgcolor: "var(--colors-surface-elevated)", color: "var(--colors-text-primary)" }}>

// UnoCSS (presetWind4 + theme tokens)
<div className="bg-surface-base text-primary border-b border-whisper">

// Raw CSS
.card { background: var(--colors-surface-base); }
```

Never hardcode `#1d1d1f` or `#f4606c` — always go through tokens so light/dark and AA-safe variants resolve correctly.
