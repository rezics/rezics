# State Layer

rezics communicates interactive state through **quiet rectangular tints** at fixed opacity tiers. The overlay color is `currentColor` so contrast tracks the element's text role; the overlay shape is the element's own bounding box, not an organic ripple. The aesthetic is borderless and quiet, not Material brand.

## The 8 / 12 / 12 / 16 ladder

| State | Opacity | Token | Trigger |
| --- | --- | --- | --- |
| Hover | `0.08` | `--state-hover-opacity` | Pointer over interactive element |
| Focus | `0.12` | `--state-focus-opacity` | Keyboard focus (`:focus-visible`) |
| Pressed | `0.12` | `--state-pressed-opacity` | `:active` press in progress |
| Dragged | `0.16` | `--state-dragged-opacity` | Element under drag |

The values come from MD3's overlay system (`08/12/12/16`). They scale gently across the light canvas and dark canvas without re-tuning per role.

## How to apply

Three UnoCSS shortcut classes wire the ladder to standard React event triggers:

```tsx
<button className="relative state-hover state-focus state-pressed">
  Save
</button>
```

The shortcuts emit a `::before` pseudo-element with `bg-current`, opacity 0 in resting state, transitioning to the ladder opacity on the matching event. The element MUST own `position: relative` and have meaningful `color` (which the overlay reads via `currentColor`).

## We don't do this

<Compare>
  <Do caption="Quiet rectangular tint">
    The overlay is the element's own bounding box. The visual signature is "this surface lit up slightly," not "something happened *at* a point." Reads consistently against plain canvas without shouting.
  </Do>
  <Dont caption="MD3 full-bleed circular ripple">
    The ripple's organic-spread visual signature reads as Material brand against any canvas. It also pulls attention to the touch point, which competes with the quiet archive aesthetic. rezics uses a flat tint instead.
  </Dont>
</Compare>

## Reference

> **MD3 state layers**: m3.material.io/foundations/interaction/states/overview — the 8/12/12/16 opacity ladder is adopted verbatim. rezics rejects the full-bleed ripple animation and the tonal-elevation signal Material adds on top of state changes; the rezics surface ladder ([Depth Without Shadow](?path=/docs/foundation-patterns-depth-without-shadow--docs)) handles depth, the state layer only handles interaction.
