# Card Surfaces

Rezics uses shadcn `<Card>` as the canonical card primitive. Card radius is
small and consistent (`rounded-md`) so image content is not overly clipped.
Large radius remains for modal and overlay surfaces.

All in-flow card surfaces keep a restrained page-color read, but each surface
has a distinct depth contract:

- `plain`: no outer chrome; interactive hover uses a Reddit-like tonal state
  layer.
- `contained`: `surface-subtle` tonal fill without border or shadow, for
  ordinary panel cards that need to separate from the page color.
- `elevated`: same-color card with shadow lift for media-rich articles and
  recommendations.

Hover, pointer cursor, and focus treatment are opt-in through `interactive`.
Static cards do not pretend to be clickable. Interactive `plain` cards reserve
an outer state-layer ring, so their content area is intentionally smaller than
`contained` and `elevated` at the same outer size.

`elevated` accepts `elevation={1..10}` for visual calibration. Keep production
choices low enough that the card still reads as in-flow content, not modal
chrome.

`Card` owns the named `@container/card` query context. Consumers can use
`@[...]/card:` modifiers without repeating `className="@container/card"`.

Media belongs flush to the card edge for `contained` and `elevated`. Use
`CardMedia` for non-`img` media blocks so mocks, video, and composed artwork
receive the same top-edge treatment as direct images. Interactive `plain` cards
keep media inside their outer hover ring.

export function MockImage({ tone = "warm" }) {
  const bg =
    tone === "cool"
      ? "linear-gradient(135deg, var(--colors-surface-sunken) 0%, var(--colors-surface-base) 55%, var(--colors-surface-elevated) 100%)"
      : "linear-gradient(135deg, var(--colors-surface-subtle) 0%, var(--colors-surface-base) 45%, var(--colors-brand-container) 100%)";

  return (
    <CardMedia
      style={{
        aspectRatio: "16 / 9",
        background: bg,
        display: "flex",
        alignItems: "center",
        justifyContent: "center",
        gap: 12,
      }}
    >
      <div
        style={{
          width: 44,
          height: 72,
          borderRadius: 4,
          background: "var(--colors-surface-canvas)",
          boxShadow: "0 4px 12px rgba(0,0,0,0.12)",
        }}
      />
      <div
        style={{
          width: 44,
          height: 72,
          borderRadius: 4,
          background: "var(--colors-brand-fill)",
          boxShadow: "0 4px 12px rgba(0,0,0,0.12)",
          transform: "rotate(7deg)",
        }}
      />
      <div
        style={{
          width: 44,
          height: 72,
          borderRadius: 4,
          background: "var(--colors-surface-subtle)",
          boxShadow: "0 4px 12px rgba(0,0,0,0.12)",
          transform: "rotate(-6deg)",
        }}
      />
    </CardMedia>
  );
}

export function SampleCard({
  surface,
  withImage = false,
  title,
  description,
  tone,
}) {
  return (
    <Card surface={surface} interactive className="max-w-xs">
      {withImage && <MockImage tone={tone} />}
      <CardHeader>
        <CardTitle>{title}</CardTitle>
        <CardDescription>{description}</CardDescription>
      </CardHeader>
      <CardContent>
        <p className="m-0 text-sm leading-ui text-text-secondary">
          Same outer radius and media rules. The surface prop controls depth;
          interactive controls hover, cursor, and focus treatment.
        </p>
      </CardContent>
    </Card>
  );
}

## Avoid

Do not hand-roll a card by combining a different fill, large radius, and custom
shadow. Pick the closest `surface` value and use `CardMedia` for flush media
instead.

<div className="max-w-xs rounded-2xl bg-surface-base p-4 shadow-md">
  <div className="aspect-[16/9] rounded-xl bg-surface-subtle" />
  <p className="mb-0 mt-3 text-sm font-medium">Hand-rolled heavy card</p>
</div>

```tsx
<Card surface="plain">...</Card>
<Card surface="contained">...</Card>
<Card surface="elevated">...</Card>
<Card surface="elevated" elevation={6}>...</Card>
<Card surface="contained" interactive>...</Card>
<CardMedia>...</CardMedia>
```
