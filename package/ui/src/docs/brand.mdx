# Brand

The visual identity of rezics — logo, brand color, and how to use them. Tokens (colors, type, spacing) live under [Tokens](?path=/docs/foundation-tokens-colors--docs). The "why" behind the mood is in [Voice](?path=/docs/foundation-voice--docs).

The single source of truth for the logo is `package/ui/src/brand/Logo.tsx` (inline SVG, accepts `size` and `color` props). The component is exported from `@rezics/ui` and follows `currentColor` when `color="currentColor"` is passed.

---

### Color variants

### Usage

```tsx
import { Logo } from "@rezics/ui";

// Default — brand-fill token, 64px
<Logo />

// Explicit size, follows surrounding text color
<Logo size={24} color="currentColor" />

// On a brand-colored hero, render in white
<Logo size={96} color="#fff" />
```

### Clear space

Reserve at least `½ × logo height` of empty space on every side. Don't crowd the logo with text, icons, or chrome — it's a punctuation mark, not a button.

## Brand color

**轮回红** `#f4606c` — the only branded accent in the system. Resolved through `--rezics-color-brand-fill`. The text-safe counterpart `--rezics-color-text-brand` auto-resolves to AA-safe values: `#C4433A` in light mode, `#fa7882` in dark mode.

## Misuse

- **No raster screenshots.** Always use the SVG component or the source `.svg`. The logo must remain crisp at every density.
- **No recoloring outside the brand fill or `currentColor`.** Especially: no neutral grays, no muted tints, no inverted negatives, no two-tone splits.
- **No "wordmark" composites.** There is no rezics wordmark in the design system at the moment. If you need text alongside the logo, use the standard typography stack and treat the logo as an icon to the left.
- **No favicon-only fallback in the app.** `package/app/public/logo.svg` and `package/admin/public/logo.svg` exist for `<link rel="icon">`. Inside JSX always use `<Logo />`.
