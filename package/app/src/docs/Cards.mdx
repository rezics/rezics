# Cards

Each domain entity has a card. They follow the **content-led** card rules from
[`Foundation/Patterns#cards`](?path=/docs/foundation-patterns--docs): no border,
no shadow, no card chrome — image + title + secondary metadata.

## Books

Books split horizontal vs vertical because the **layout test fires**: the
horizontal card stacks cover-left + body-right (search results, ranking lists);
the vertical card stacks cover-top + body-bottom (carousels, grids).

- [`BookCardHorizontal — Default / LongContent / Empty / LocaleCJK / LocaleLatin`](?path=/story/app-book-bookcardhorizontal--default)
- [`BookCardVertical — Default / LongContent / Empty / LocaleCJK / LocaleLatin`](?path=/story/app-book-bookcardvertical--default)

## User-authored content

Reviews, excerpts, remarks, shelves, and realms each have one card. They share
the *Default / LongContent / LocaleCJK / LocaleLatin* axes wherever the body is
freeform prose.

- [`ReviewCard`](?path=/story/domain-review-reviewcard--default) ·
  [`ReviewCardPair`](?path=/story/domain-review-reviewcardpair--default)
- [`ExcerptCard`](?path=/story/domain-excerpt-excerptcard--default)
- [`RemarkCard`](?path=/story/domain-remark-remarkcard--default)
- [`ShelfCard`](?path=/story/domain-shelf-shelfcard--default) ·
  [`ShelfItemCard`](?path=/story/domain-shelf-shelfitemcard--default)
- [`RealmCard — Default / Compact / Hero`](?path=/story/domain-realm-realmcard--default)

`RealmCard` uses **Hero** for the official-realm large variant — the layout
*does* change, but the prop API stays unified, so it's still a variant prop, not
a split.
