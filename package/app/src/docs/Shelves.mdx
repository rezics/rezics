# Shelves

A shelf is a curated, ordered set of items (books, reviews, excerpts). It's the
core of the "library" metaphor: users build their own catalog, and other readers
browse it.

## Cards & lists

- [`ShelfCard — Default / Empty / LongContent / Large`](?path=/story/domain-shelf-shelfcard--default) — discoverable in a feed.
- [`ShelfList — Default / Empty`](?path=/story/domain-shelf-shelflist--default) — a list of shelves.
- [`ShelfItemCard — Default / LongContent / Compact`](?path=/story/domain-shelf-shelfitemcard--default) — one item inside a shelf.

## Discussion

Shelves carry their own discussion thread. `ShelfDiscussionSection` reuses the
post-tree machinery but scoped to a `shelfUnitId`. Stories cover the three
auth/data states:

- [`ShelfDiscussionSection — Default / Empty / Many / Disabled (signed-out)`](?path=/story/app-shelf-shelfdiscussionsection--default)

## Patterns at play

`ShelfCard` follows the borderless card rule — no border, no shadow, content
leads. `ShelfItemCard` ships a `Compact` variant for inline-list rendering; the
prop API stays unified, so it's a **variant prop** not a split.
See [`Foundation/Patterns#cards`](?path=/docs/foundation-patterns--docs).
