# Post Flow Cards

Post flow cards are app-side content-flow surfaces. They are used by places
such as book discussions, shelf discussions, and realm feeds where the data is a
`PostDTO` and the surface owns engagement behavior.

They live with app card components rather than the post domain folder. Search
result cards solve preview layout for mixed search hits; post flow cards solve
document-flow presentation with author metadata, body preview, and `ReactionBar`.

## Default flow card

`PostFlowCard` is the default text-first post card. The right thumbnail is
optional and must remain secondary to the text.

## Media flow card

`PostFlowMediaCard` is only for media-forward posts. It is not the default for
ordinary reviews, remarks, quotes, or discussions.

<div className="max-w-[45.75rem] bg-surface-canvas p-4 text-text-primary">
  <Canvas of={PostFlowCardStories.MediaForward} />
</div>

```tsx
<PostFlowCard post={post} />

<PostFlowCard
  post={post}
  title={resolvedTitle}
  media={{ src: thumbnailUrl, alt: "" }}
  reactionPolicy={remarkPolicy}
  reactionActions={remarkCardActions}
/>

<PostFlowMediaCard
  post={post}
  title={resolvedTitle}
  media={{ src: imageUrl, alt: "" }}
/>
```
