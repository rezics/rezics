# Profile & settings

The profile surface and the settings surface share a header layout but carry
different content. They split into two top-level shells:

- **Profile** — public; reading activity, shelves, follows.
- **Settings** — private; account, sessions, tokens, danger zone.

## Profile shell

- [`ProfileBasicInfo — Default / Empty / Compact`](?path=/story/domain-user-profilebasicinfo--default) — name, avatar, bio, follow button.
- [`ProfileTabBar`](?path=/story/domain-user-profiletabbar--default) — overview / shelves / posts / reviews tabs.

## Settings shell

- [`SettingsSidebar`](?path=/story/domain-user-settingssidebar--default) — left rail nav.
- [`SettingsTabBar`](?path=/story/domain-user-settingstabbar--default) — top tab nav (mobile).
- [`SettingsSection — Default / Empty`](?path=/story/domain-user-settingssection--default) — titled section with optional description + divider.

## Sub-surfaces

- [`FilterBar — Default / Compact`](?path=/story/domain-user-filterbar--default) — searches + dropdowns over a list (shelves, sessions).
- [`DangerZone`](?path=/story/domain-user-dangerzone--default) — account-deletion section.
- [`ProviderCard — Default / Compact / Loading`](?path=/story/domain-user-providercard--default) — connected OAuth provider.
- [`SocialAuthButtons — Default / Compact`](?path=/story/domain-user-socialauthbuttons--default) — sign-in / register provider row.
- [`SessionListItem — Default / Compact / Loading`](?path=/story/domain-user-sessionlistitem--default) — active session row.
- [`TokenListItem — Default / Compact`](?path=/story/domain-user-tokenlistitem--default) — API token row.
- [`AuthModal — Default / Compact / HappyPath`](?path=/story/domain-user-authmodal--default) — sign-in / register dialog.
- [`OtpInput — Default / Compact / Disabled / HappyPath`](?path=/story/domain-user-otpinput--default) — segmented OTP entry.
- [`TokenCreateDialog — Default`](?path=/story/domain-user-tokencreatedialog--default) — generate-API-token dialog.

## Patterns at play

`SettingsSection` follows the borderless-section rule from
[`Foundation/Patterns#section--page-layout`](?path=/docs/foundation-patterns--docs)
— whitespace separates, optional whisper-divider line, no card chrome.
