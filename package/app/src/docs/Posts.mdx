# Posts & threading

Posts power both flat comment streams (under shelves, books, reviews) and the
deep threaded discussions on the post detail surface. The split between the two
top-level components is intentional:

- **`PostCard`** — flat single-post surface (post detail page header, search
  results). 2 props.
- **`PostReply`** — tree node with collapse/expand + threading rail + reply
  composer slot. 6 props.

Prop overlap is ~17 % (only `post` is shared). The **layout test fires** on
PostReply (it renders the threading rail and a collapse toggle that PostCard
doesn't have), so they stay split. See [`Foundation/Patterns`](?path=/docs/foundation-patterns--docs).

data-shape stories cover the four interesting axes:
