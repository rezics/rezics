# Series And Work Readiness

Series are public-knowledge catalog structures. Season groups, episode groups,
arcs, discs, tracks, volumes, and source-specific orderings belong to
content-structure metadata or future structure variants, not `Series.kindKey`.

Work pages may use `work/:unitId` for abstract maintenance and release-list
inspection. Work `UnitTranslation` editing is Work abstract identity metadata,
not ordinary release display metadata.

Any new direct Work-targeted relation or interaction must stop for explicit
design review and human confirmation before implementation. This includes direct
Work posts, reviews, shelves, ratings, Series membership, follows, progress, or
any relation whose direct target is a hidden Work Unit instead of a visible
release Unit.
