## 創作の豊かさに向けた公開索引

Rezics は本から始まります。Web 文学がこの問題を見過ごせないものに
したからです。ただし目標はもっと広く、どんな作品も言語、プラットフォーム、
コミュニティの境界を越えて見つけられるべきです。

## 知識を作品のそばに置く

カタログ、レビュー、棚、wiki 知識、Realm の議論は、同じ作品 ID に戻ります。
継承された知識が、どこから来たのかを失わずに次へ進むためです。
