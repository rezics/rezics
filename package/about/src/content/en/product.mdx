## The product boundary

The about package should explain the product without duplicating it. Discovery, editing, voting, saving, and realm administration remain in the main Rezics app where authentication and application state already live.

## Why this page is static

The public product story changes deliberately. Keeping it as localized MDX makes the page easy to translate and review while keeping runtime dependencies away from the about-site deployment.
