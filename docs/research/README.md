# Open research

This directory holds unresolved questions that can change the design. Conduct autonomous web research and experiments under [the program's environment authorization](../plan/README.md). Prefer primary evidence and record the decision it supports, uncertainty and the owning module.

Current open scope: [Skill, Prompt and MCP execution/hosting](ai-hub-execution.md).

Selected contracts and their supporting sources live in the
[architecture evidence matrix](../architecture/database/design-evidence.md).
Research notes are not a second authority for adopted Work, composition or
logical identity rules.

When a question is resolved, move the selected contract and tests into their owners and delete the research note. Completed audits, obsolete proposals and execution diaries are not retained here; Git provides history. Known reproducible failures live in [testing](../testing/known-failures.md), and remaining implementation work lives in the plan.
