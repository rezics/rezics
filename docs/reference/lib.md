## html-to-image

|                | html-to-image                    | Satori                                 |
| -------------- | -------------------------------- | -------------------------------------- |
| Input          | Real DOM                         | JSX (flex only)                        |
| CSS support    | Almost full                      | Flex only                              |
| Environment    | Browser only                     | Browser / Node / Edge                  |
| Mechanism      | DOM → SVG foreignObject → Canvas | JSX → SVG (custom layout engine)       |
| Best use cases | Screenshot existing UI           | Generate OG images, headless rendering |
