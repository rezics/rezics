# REZICS 1.6.0

REZICS 1.6.0 replaces the development-preview SearchDocument and preset model
with one sparse FilterDocument contract. An empty document is an empty set of
conditions. Search limits, indexed capabilities, sorts, and fallbacks are owned
by the server; Book, Media, Software, Realm, and Zone discovery are Zones with
ordinary persisted Filter documents.

This is a breaking preview API and persisted-contract release. Template routes,
Zone Search Feature CRUD/history routes, template query parameters, and legacy
Block template sources are removed. Global, Zone-owned, inline, shared-query,
Block, Search, Feed, and Progress paths now resolve through the same Filter
compiler.

Production data is migrated rather than discarded wholesale. A restartable,
keyset-batched worker preserves concrete Zone boundaries, explicit predicates,
administrator control overrides, shared-query behavior, current Zone Page and
Dock Blocks, and restorable Unit/Dock history. It drops generated defaults and
limit-only capability configuration. Atlas then removes all SearchDocument
tables and their unreferenced history blobs.

Deploy every component together during the required maintenance cutover. The
full data, capacity, verification, and rollback procedure is in
[Unified Filter documents](../architecture/filter-documents.md#160-production-cutover).
