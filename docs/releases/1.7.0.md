# REZICS 1.7.0

REZICS 1.7.0 replaces human governance reason codes with immutable Realm Rule
decisions, adds a shared cross-domain decision ledger, and lets a Zone select
an optional local Rule Realm without making Zone a policy owner. The matching
backend and web release is 1.7.0; the matching breaking public TypeScript client
release is `@rezics/api@1.10.0`.

The database upgrade is in place: it preserves operational and audit rows,
deletes obsolete reason values without fabricating Rule evidence, and marks
pre-cutover domain links as absent. The official Rule Realm identity remains
bootstrap-owned, while its revisions and Rule Units move to online history; a
separate Seed publishes starter Rules only for a fresh Realm.

This is a coordinated breaking release. See
[the governance Rule cutover](./1.7.0-governance-rule-cutover.md) for deployment
and rollback requirements, and
[Governance Rule decisions](../architecture/governance-rule-decisions.md) for
the data, concurrency, and capacity design.
