## Was es ermöglicht

Token macht das Grundmodell für Lesende verständlich und für Communities dauerhaft pflegbar. Trägt Berechtigungen und Nutzungsgrenzen in einem maschinenprüfbaren Zugangsnachweis.

## Wer es nutzt

Entwicklungsteams und Community-Werkzeuge verbinden sich mit klaren Rechten mit REZICS, ohne ein zweites Identitätssystem zu schaffen.

## Ein konkreter Weg

- Eine Anwendung verbindet sich mit ausdrücklicher Berechtigung einer Person mit REZICS.
- Ein Token erhält nur die gewährten Bereiche.
- Ein Widerruf beendet den Zugriff auf geschützte Fähigkeiten.

## Wie es funktioniert

1. Eine Person oder Verwaltung erteilt die Berechtigung.
2. OAuth stellt ein Token mit begrenztem Umfang aus.
3. Die API prüft Identität, Umfang und Grenzen bei jeder Anfrage.

## Wie es verbunden ist

Token steht nicht allein, sondern teilt Identität, Kontext oder Abläufe mit API & OAuth · Inhaltsstruktur · Editor · Werk.

## Klare Grenzen

- Ein Token ist keine Werkidentität und trägt keine redaktionellen Inhalte.
- Es umgeht weder Community-Regeln noch Veröffentlichungslizenzen.
- Geheimnisse und Zugangsdaten gehören nie auf öffentliche Seiten.
