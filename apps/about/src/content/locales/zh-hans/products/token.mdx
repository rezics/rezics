## 它带来什么

令牌，把底层模型转成读者能理解、社区能长期维护的能力。把授权范围与使用限制带入机器可验证的访问凭证。

## 谁会使用

开发者与社区工具用它在清楚授权下连接 REZICS，而不用另造一套身份。

## 一段具体旅程

- 应用以明确权限代表用户连接 REZICS。
- 令牌只能取得被授予的范围。
- 撤销后不再访问受保护能力。

## 如何运作

1. 由用户或管理员建立授权。
2. OAuth 流程签发带范围的令牌。
3. API 在每次请求验证身份、范围和限制。

## 如何连接

令牌并不孤立；它与 API 与 OAuth · 内容结构 · 编辑器 · 作品 共享身份、语境或工作流程。

## 清楚的边界

- 令牌不是作品身份，也不承载内容。
- 它不会绕过社区规则或公开许可。
- 密钥与凭证不会出现在公开页面。
