## 它带来什么

编辑器，把底层模型转成读者能理解、社区能长期维护的能力。让不同内容类型共享一致但可扩展的编辑工作流。

## 谁会使用

作者和编辑者用它组合内容、发布变更，读者则得到连贯且可追溯的结果。

## 一段具体旅程

- 让不同内容类型共享一致但可扩展的编辑工作流。
- 编辑器 只连接注册表明确列出的共享能力。

## 如何运作

1. 建立或选择 编辑器 的稳定记录。
2. 在产品自己的界面完成核心任务。
3. 发布后由相关 History 与 API 能力承接。

## 如何连接

编辑器并不孤立；它与 帖子 · 书籍 · 内容结构 · 历史 · API 与 OAuth 共享身份、语境或工作流程。
