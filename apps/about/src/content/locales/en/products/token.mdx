## What it makes possible

Token turns the underlying model into something readers can understand and communities can maintain. Carries authority and usage limits in a machine-verifiable access credential.

## Who uses it

Developers and community tools connect to REZICS with explicit authority instead of creating a second identity system.

## A concrete journey

- An application connects to REZICS on a person’s explicit authority.
- A token receives only the granted scopes.
- Revocation ends access to protected capabilities.

## How it works

1. A person or administrator establishes authority.
2. The OAuth flow issues a scoped token.
3. The API checks identity, scope, and limits on every request.

## How it connects

Token does not stand alone. It shares identity, context, or workflow with API & OAuth · Content Structure · Editor · Work.

## Clear boundaries

- A token is not a work identity and carries no editorial content.
- It does not bypass community rules or publication licenses.
- Secrets and credentials never belong on public pages.
