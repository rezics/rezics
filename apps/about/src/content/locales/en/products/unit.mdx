## What it makes possible

Work turns the underlying model into something readers can understand and communities can maintain. Every work begins with one stable identity, then carries languages, types, releases, content, and community relationships.

## Who uses it

Readers use it to recognize the same work; communities use it to preserve context; editors use it to prevent duplication and fragmentation.

## A concrete journey

- A reader finds languages, editions, and media forms through one work identity.
- Community discussion, knowledge, and attribution return to that same work.
- New content extends an existing identity instead of creating another isolated entry.

## How it works

1. Establish an unambiguous work identity.
2. Attach localized names, type metadata, and release relationships.
3. Let content, collections, communities, and open interfaces reference that identity.

## How it connects

Work does not stand alone. It shares identity, context, or workflow with Book · Media · Software · Series · Release · Entity · Tag.

## Clear boundaries

- A work identity is not one language-specific title.
- It does not collapse releases, editions, and series into one concept.
- Communities add knowledge without rewriting the work’s identity.
