## 가능하게 하는 것

API 및 OAuth: 기반 모델을 독자가 이해하고 커뮤니티가 오래 관리할 수 있는 기능으로 바꿉니다. 권한 기반 API, OAuth, MCP로 REZICS를 외부와 연결합니다.

## 사용하는 사람

개발자와 커뮤니티 도구가 별도 정체성 체계를 만들지 않고 명확한 권한으로 REZICS에 연결됩니다.

## 구체적인 여정

- 권한 기반 API, OAuth, MCP로 REZICS를 외부와 연결합니다.
- API 및 OAuth는 등록부에 명시된 공유 기능만 연결합니다.

## 작동 방식

1. 안정적인 API 및 OAuth 레코드를 고릅니다.
2. 제품 고유 화면에서 핵심 작업을 끝냅니다.
3. 공개 뒤에는 History와 API가 이어받습니다.

## 연결 방식

API 및 OAuth: 토큰 · 콘텐츠 구조 · 편집기 · 피드 · 엔터티 등과 함께 정체성, 맥락, 작업 흐름을 연결합니다.

## 분명한 경계

- 내부 프로토콜은 관련 페이지와 개발 문서에 둡니다.
- 내비게이션은 도메인 관계를 바꾸지 않습니다.
