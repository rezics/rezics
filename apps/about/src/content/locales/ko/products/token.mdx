## 가능하게 하는 것

토큰: 기반 모델을 독자가 이해하고 커뮤니티가 오래 관리할 수 있는 기능으로 바꿉니다. 권한 범위와 사용 한도를 기계가 검증할 수 있는 접근 자격에 담습니다.

## 사용하는 사람

개발자와 커뮤니티 도구가 별도 정체성 체계를 만들지 않고 명확한 권한으로 REZICS에 연결됩니다.

## 구체적인 여정

- 애플리케이션은 사용자의 명시적 권한으로 REZICS에 연결됩니다.
- 토큰은 허용된 범위만 받습니다.
- 철회하면 보호된 기능에 더 이상 접근할 수 없습니다.

## 작동 방식

1. 사용자나 관리자가 권한을 설정합니다.
2. OAuth 흐름이 범위가 지정된 토큰을 발급합니다.
3. API는 요청마다 정체성, 범위, 한도를 확인합니다.

## 연결 방식

토큰: API 및 OAuth · 콘텐츠 구조 · 편집기 · 작품 등과 함께 정체성, 맥락, 작업 흐름을 연결합니다.

## 분명한 경계

- 토큰은 작품 정체성이 아니며 편집 콘텐츠를 담지 않습니다.
- 커뮤니티 규칙이나 게시 라이선스를 우회하지 않습니다.
- 비밀키와 자격 증명은 공개 페이지에 두지 않습니다.
