## 可能になること

エディターは、基盤モデルを読者が理解でき、コミュニティが維持できる形にします。異なる内容型で共有する拡張可能な編集ワークフローです。

## 利用する人

作者と編集者が内容を構成して公開し、読者は一貫した追跡可能な結果を受け取ります。

## 具体的な体験

- 異なる内容型で共有する拡張可能な編集ワークフローです。
- エディター は登録済みの共有機能だけを接続します。

## 仕組み

1. エディター の安定レコードを選びます。
2. 固有の画面で中心作業を完了します。
3. 公開後は History と API が後続処理を担います。

## つながり

エディターは単独ではなく、投稿 · 書籍 · コンテンツ構造 · 履歴 · API と OAuthと識別、文脈、作業の流れを共有します。
